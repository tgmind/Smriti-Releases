### Distribution Architecture
This repository is the **official public binary distribution repository** for SMRITI. It provides compiled application binaries, installation packages (APKs), release notes, and cryptographic checksums.

No source code is hosted in this repository.

### Latest Releases
- **[Latest Release Downloads](https://github.com/tgmind/Smriti-Releases/releases/latest)**
- **Pre-signed Android Debug APK (`app-debug.apk`)**: Installs immediately on any Android device (Android 7.0+).
- **Optimized Release APK (`app-release-unsigned.apk`)**: Compiled with baseline profile optimizations.

### Integrity Verification
All releases include a SHA-256 checksum file (`checksums.sha256`) allowing verification of the downloaded binary.
